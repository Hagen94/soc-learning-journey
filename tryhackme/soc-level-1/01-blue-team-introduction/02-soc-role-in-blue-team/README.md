# SOC Role in Blue Team

## Overview

This room explains how the Blue Team fits into an organization's security structure and how the Security Operations Center (SOC) collaborates with other security departments. It also introduces common Blue Team career paths and the progression from an entry-level SOC analyst to more specialized cybersecurity roles.

---

## Learning Objectives

After completing this room, I am able to:

- Understand the purpose of the Blue Team.
- Explain how the SOC fits into an organization's security hierarchy.
- Identify the main security departments within an organization.
- Describe common Blue Team roles and responsibilities.
- Understand possible career paths for a SOC analyst.

---

## Key Concepts

### Security Hierarchy

Organizations structure their security teams according to business needs and risk priorities. Security leadership is typically overseen by a Chief Information Security Officer (CISO), who coordinates multiple security departments.

---

### Security Departments

Common security departments include:

| Team              | Primary Responsibility |
|-------------------|-------------------------|
| Red Team          | Simulates attacks to identify security weaknesses |
| Blue Team         | Detects, investigates, and responds to security incidents |
| GRC               | Manages governance, risk, compliance, and security policies |

---

### Blue Team

The Blue Team focuses on defensive cybersecurity by continuously monitoring systems, detecting threats, and responding to security incidents.

Common Blue Team functions include:

- Security monitoring
- Incident detection
- Incident response
- Threat analysis
- Security engineering

---

### Security Operations Center (SOC)

The SOC acts as the organization's central monitoring and response team.

Typical SOC roles include:

| Role                   | Responsibilities                          |
|------------------------|-------------------------------------------|
| SOC L1 Analyst         | Monitor alerts and perform initial triage |
| SOC L2 Analyst         | Investigate complex incidents             |
| SOC Engineer           | Configure and maintain security tools     |
| SOC Manager            | Lead SOC operations                       |

---

### Cyber Incident Response Team (CIRT)

The Cyber Incident Response Team (CIRT) handles major security incidents when an attack exceeds normal SOC capabilities.

Typical responsibilities include:

- Incident containment
- Eradication
- Recovery
- Incident coordination

---

### Specialized Blue Team Roles

As experience grows, professionals may specialize in areas such as:

- Digital Forensics
- Threat Intelligence
- Application Security (AppSec)
- Security Engineering
- AI Security Research

---

## Internal SOC vs MSSP

The room introduces two common working environments.

| Internal SOC                         | MSSP                                    |
|------------------------------------- |-----------------------------------------|
| Protects a single organization       | Protects multiple customers             |
| Greater knowledge of one environment | Exposure to many different environments |
| Usually fewer tools                  | Usually many different platforms        |
| Lower operational pressure           | Higher alert volume and faster pace     |

---

## Career Perspective

A SOC Level 1 position is an excellent starting point for developing practical cybersecurity skills.

Possible career progression includes:

- SOC Level 2 Analyst
- SOC Engineer
- Incident Responder
- Threat Hunter
- Digital Forensics Analyst
- Security Manager
- Chief Information Security Officer (CISO)
