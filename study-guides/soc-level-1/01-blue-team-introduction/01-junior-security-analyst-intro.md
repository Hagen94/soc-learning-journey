# Learning Summary

This room introduces the fundamentals of working in a Security Operations Center (SOC). It explains the purpose of a SOC, the responsibilities of a Junior Security Analyst (SOC L1), the different roles within the team, and why continuous learning is essential in cybersecurity.

**Goal:** Understand how a SOC operates and the role of a SOC Level 1 analyst in defending an organization.

---

# Key Concepts

## Security Operations Center (SOC)

A centralized team responsible for monitoring, detecting, investigating, and responding to cybersecurity threats.

### Main Objectives

- Monitor security events
- Detect malicious activity
- Investigate alerts
- Respond to incidents
- Protect organizational assets

---

## Junior Security Analyst (SOC L1)

The SOC L1 analyst is the first person to investigate security alerts.

Typical responsibilities:

- Monitor SIEM alerts
- Perform alert triage
- Investigate suspicious events
- Escalate incidents when necessary
- Document findings

---

## SOC Team Roles

| Role | Main Responsibility |
|------|---------------------|
| SOC L1 | Initial investigation |
| SOC L2 | Complex investigations |
| SOC Engineer | Security tools |
| Incident Responder | Major incidents |
| SOC Manager | Team management |

---

## Continuous Learning

Cyber threats constantly evolve.

A SOC analyst must continuously improve technical knowledge, investigation techniques, and familiarity with security tools.

---

# Important Definitions

## Event

Any observable activity occurring in a system.

Example:

A user logs into Windows.

---

## Alert

A notification generated because suspicious activity was detected.

Example:

The SIEM detects multiple failed login attempts.

---

## Incident

A confirmed security event that requires investigation and response.

Example:

A compromised user account.

---

## Alert Triage

The process of evaluating an alert to determine its priority and whether further investigation is required.

---

## Escalation

Forwarding an incident to a higher-level analyst when additional expertise is needed.

# Common Mistakes

❌ Thinking every alert is an incident.

❌ Closing alerts without investigation.

❌ Escalating incidents too early.

❌ Ignoring documentation.

❌ Believing cybersecurity is only about technical knowledge.
